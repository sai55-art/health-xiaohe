## 各模块数据流详解

### 1. Auth (认证)

```
UI LoginPage  ──AuthLoginRequested──► AuthBloc ──login(phone,pwd)──► AuthRepoImpl
    ▲                                                                   │
    │                                                         POST /api/auth/login
    │                                                                   │
    └── AuthAuthenticated(user) ◄── yield state ◄── UserModel ◄────────┘
                                                      +
                                               JWT → LocalStorage
```

### 2. Chat (AI 对话 — SSE 流式)

```
UI ChatHomePage ──ChatSendMessage──► ChatBloc ──getChatStream()──► ChatRepoImpl
    ▲    ▲                                                              │
    │    │                                                  POST /api/consult/chat/stream
    │    │                                                              │
    │    ├── ChatReceiveStreamChunk ◄── SseChunk ◄── SSE data:{} ◄─────┤
    │    │    (逐字更新最后一条 AI 消息)                                   │
    │    │                                                       AIService.chat_stream()
    │    │                                                              │
    │    │                                                    MemoryService.enrich()
    │    │                                                    (注入画像+记忆+记录)
    │    │                                                              │
    │    │                                                    DashScope qwen-max
    │    │                                                    (HTTP stream)
    │    │
    │    └── ChatStreamCompleted (conversationId 回传, 自动持久化)
    │
    └── 欢迎建议: ChatLoadWelcomeSuggestions ──► GET /api/consult/welcome-suggestions
```

### 3. Chat History (对话历史)

```
UI ChatHistoryPage ──LoadConversations──► ChatHistoryBloc ──getConversations()──► ChatRepoImpl
    ▲                                                                                 │
    │                                                                    GET /api/consult/conversations
    │                                                                                 │
    └── success(conversations) ◄── List<ConversationItem> ◄──────────────────────────┘

UI ConversationDetailPage ──LoadDetail──► ChatHistoryBloc ──getConversationDetail(id)──► GET /conversations/{id}
```

### 4. Health Records (健康记录)

```
UI HealthRecordsPage ──LoadRecords──► HealthBloc ──getRecords()──► HealthRepoImpl
    ▲                                                                  │
    │                                                       GET /api/health/records
    │                                                                  │
    └── HealthLoaded(records) ◄────────────────────────────────────────┘

创建: CreateRecord ──► HealthBloc ──createRecord()──► POST /api/health/records
                        │
                        └── 成功后自动触发 HealthLoadRecords (refresh)
```

### 5. Voice Call (语音实时通话)

```
Flutter                        Backend                          DashScope
───────                        ───────                          ────────

WebSocket ──audio chunk──►   voice_ws ──append──►    Realtime WS
          ──image chunk──►           ──append──►
          ──commit───────►           ──commit──►
                                       │
          ◄──text delta───           ◄──audio_transcript.delta──
          ◄──audio delta──          ◄──response.audio.delta──
          ◄──speech_started──       ◄──input_audio_buffer.speech_started──
          ◄──user_text────          ◄──input_audio_transcription.completed──
          ◄──ai_text──────          ◄──response.audio_transcript.done──
          ◄──done─────────          ◄──response.done──

状态流转: VoiceConnecting → VoiceConnected ⇄ VoiceListening ⇄ VoiceReceivingText/Audio
```

## 数据模型层次

| 层次 | Auth | Chat | Health | Voice |
|------|------|------|--------|-------|
| **UI State** | AuthState 子类 | ChatState (copyWith) | HealthState 子类 | VoiceState 子类 |
| **Domain Model** | UserModel | ChatMessageModel | HealthRecordModel | (Map) |
| **API Schema** | UserResponse | ChatRequest/Response | HealthRecordResponse | JSON type messages |
| **DB Model** | User | Conversation, Message | HealthRecord | Conversation, Message |
